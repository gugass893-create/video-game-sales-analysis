# video-game-sales-analysis

# Анализ продаж видеоигр

Учебный проект по базам данных: исследуем рынок видеоигр и выясняем, **какие жанры, игровые платформы и издатели наиболее успешны**. Данные хранятся в базе SQLite, а результаты запросов оформлены в Excel.

> Все продажи указаны в **миллионах копий**.

## Источник данных

Набор данных **Video Game Sales** (`vgsales.csv`): **16 598 записей и 11 столбцов** — `Rank`, `Name`, `Platform`, `Year`, `Genre`, `Publisher`, `NA_Sales`, `EU_Sales`, `JP_Sales`, `Other_Sales`, `Global_Sales`. В нём названия игр, платформы, годы выпуска, жанры, издатели и продажи в Северной Америке, Европе, Японии и других странах.

Файл `data/vgsales.csv` — выгрузка листа «Исходные_данные» из `excel/Первичный_аудит_видеоигр_SQLite.xlsx`; пустая ячейка означает пропущенное значение.

**Что показал первичный аудит**

- В столбце `Year` пропущено 271 значение, в `Publisher` — 58.
- Продажи даны в миллионах копий, это нужно учитывать при анализе.
- Датасет не актуален, поэтому по нему нельзя оценивать текущее состояние рынка.

## База данных (SQLite)

Для учебной базы взята **выборка из 399 записей о продажах**, а не весь датасет. Схема — 6 связанных таблиц.

| Таблица | Назначение | Основные поля | Записей |
|---|---|---|---|
| `Genres` | справочник жанров | `genre_id` (PK), `genre_name` (UNIQUE), `description` | 12 |
| `Publishers` | справочник издателей | `publisher_id` (PK), `publisher_name` (UNIQUE), `country` | 38 |
| `Platforms` | справочник платформ | `platform_id` (PK), `platform_name` (UNIQUE), `platform_type` | 22 |
| `Games` | игры | `game_id` (PK), `name`, `year`, `publisher_id` (FK), `description` | 368 |
| `Game_Genres` | связь «игра — жанр» (M:N) | `game_id` + `genre_id` (составной PK, оба FK) | 368 |
| `Sales` | продажи игры на платформе | `sale_id` (PK), `game_id` (FK), `platform_id` (FK), `na_sales`, `eu_sales`, `jp_sales`, `other_sales`, `global_sales`, `rank` | 399 |

**Связи**

- `Publishers` 1 → N `Games`
- `Games` 1 → N `Sales`
- `Platforms` 1 → N `Sales`
- `Genres` N ↔ M `Games` через `Game_Genres`

## Аналитические вопросы и результаты

Запросы лежат в папке `sql/`, таблицы и диаграммы — в `excel/`.

### 1. Какие жанры видеоигр приносят наибольшие мировые продажи?

Файлы: `sql/01_первый_аналитический_запрос.sql`, `excel/01_жанры_мировые_продажи.xlsx`.

| № | Жанр | Мировые продажи, млн |
|---|---|---|
| 1 | Action | 452,01 |
| 2 | Shooter | 421,10 |
| 3 | Platform | 412,48 |
| 4 | Role-Playing | 361,18 |
| 5 | Sports | 333,42 |

Лидирует **Action** (452,01 млн копий), далее Shooter и Platform. У каждой игры в выборке один жанр, поэтому сумма по жанрам равна общей сумме продаж (2 721,50 млн); если игре назначить несколько жанров, её продажи учитывались бы в каждом.

### 2. Как менялись мировые продажи видеоигр по годам?

Файлы: `sql/02_второй_аналитический_запрос.sql`, `excel/02_продажи_по_годам.xlsx`.

Охвачены годы выпуска с 1980 по 2020 (39 разных лет). Наибольшие продажи: **2006** (217,26 млн), 2009 (201,78) и 2010 (176,69). Игры без года (NULL) в расчёт не входят.

### 3. Какие платформы имеют наибольшие продажи и в каких регионах популярны?

Файлы: `sql/03_третий_аналитический_запрос.sql`, `excel/03_платформы_по_регионам.xlsx`. Ниже первые пять платформ из ТОП-10, млн копий.

|---|---|---|---|---|---|
| Wii | 401,32 | 192,99 | 133,17 | 38,47 | 36,69 |
| X360 | 310,70 | 191,14 | 89,33 | 2,78 | 27,46 |
| PS3 | 278,26 | 104,83 | 113,54 | 13,67 | 46,25 |
| PS2 | 259,88 | 121,14 | 68,30 | 23,70 | 46,78 |

Лидирует **Wii** (401,32 млн). Среди ТОП-10 платформ Северная Америка — ведущий регион у 8, Европа — у 2 (PS3, PS4); Япония не лидирует ни у одной.

## Журнал расследования (кратко)

Полный текст — `docs/Журнал_расследования_и_первый_запрос.docx`.

| Улика | Результат | Решение |
|---|---|---|
| Пропавшие значения | 1 игра без года; пустых названий нет; продаж без мирового итога нет | Оставить `NULL`, в анализе по годам исключать `WHERE year IS NOT NULL` |
| Двойники и подозрительные записи | Дублей по `(name, year, publisher_id)` и по паре «игра — платформа» нет; продажи от 0,01 до 82,74 млн; отрицательных значений нет | Удалять нечего; необычные значения сверять с первоисточником |
| Записи без связей | `PRAGMA foreign_key_check` — 0 нарушений; продаж без игры нет | Связи корректны; при загрузке включать `PRAGMA foreign_keys = ON` |

## Как запустить

Нужен SQLite (или программа DB Browser for SQLite).

```bash
# 1. создать базу и заполнить её
sqlite3 video_games.db < sql/бд_проект_все_годы.sql

# 2. выполнить аналитический запрос
sqlite3 -header -column video_games.db < sql/01_первый_аналитический_запрос.sql
```

В DB Browser for SQLite: _File → New Database_, затем _File → Import → Database from SQL file_ и выбрать `sql/бд_проект_все_годы.sql`.

## Ограничения и известные вопросы

- Выводы относятся к учебной выборке из 399 записей, а не ко всему рынку; датасет не актуален для оценки текущего состояния рынка.
- Поля `Genres.description`, `Publishers.country`, `Platforms.platform_type` и `Games.description` пока не заполнены (`NULL`).
- Поле `Sales.rank` заполнено только у 199 из 399 записей.
- В выборке есть единичные игры с годом 2017 и 2020 (минимальные продажи); их стоит сверить с первоисточником.
- Текст запроса №2 не был указан в Excel-файле, поэтому `sql/02_второй_аналитический_запрос.sql` составлен по его результатам и проверен: даёт те же значения.
